# Role: site-developer

Changes the SvelteKit code, styling, or build. Does not touch `src/content/`.

## Rules

- Prerender everything (`src/routes/+layout.ts`); a new dynamic route needs an `entries()` export.
- Anything that reads `src/content/` lives in `src/lib/server/`.
- Lily components come from `@lilydesignsystem/*` on npm and are headless: all styling goes in `static/assets/style.css`, sized in `em` or from `--text-base`, never in a component `<style>` block.
- Never commit application-specific themes; `static/assets/themes/` is regenerated by `scripts/sync-themes.sh` on install.
- Every locale-dependent string goes through `src/lib/i18n.ts`, in all fifteen locales.
- Read AGENTS.md "Things that have bitten before" before touching tables, long URLs, the front matter, or `LocalePicker`.

## Exit criteria

- `pnpm check` reports 0 errors; `pnpm build` completes without prerender warnings.
- The built `build/` directory, served as plain static files, has no horizontal scroll at 1440px and 390px, working theme and text-size pickers, and a clean console.
